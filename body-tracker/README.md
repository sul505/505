# جسمي — متتبع شد الجسم

تكلم سيري: «أكلت 3 بيضات»، «شربت ماي»، «وزني 72»، «بنش 60 كيلو 8 عدات». ينسجل بالوقت والتاريخ، يحسب السعرات والبروتين تقريبًا، ويرد عليك بصوت. التطبيق يعرض يومك وتطورك، والتنبيهات تجيك إذا تأخرت على الماي أو البروتين.

## الملفات

| الملف | وش هو |
|---|---|
| `index.html` | التطبيق (يتثبت على الجوال، ويفتح بدون نت) |
| `brain.js` | فهم الكلام العربي، قاعدة الأكل الخليجي، التنبيهات والتحليل. نفس الملف يشتغل في التطبيق والسيرفر |
| `server/server.js` | سيرفر Google Apps Script: يسجل في Google Sheets ويرد على سيري |
| `server/Code.gs` | الملف الكامل اللي تلصقه في Apps Script (مولّد: `node body-tracker/server/build.js`) |
| `server/appsscript.json` | إعدادات مشروع Apps Script |

## التشغيل (مرة وحدة)

1. **التطبيق:** في GitHub ← Settings ← Pages ← Source: *Deploy from a branch* ← الفرع `claude/body-reshape-12-week-dld8z9` والمجلد `/ (root)`. يصير الرابط `https://sul505.github.io/505/body-tracker/`. افتحه في سفاري ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
2. **السيرفر:** مشروع Apps Script فيه `Code.gs` ← نشر ← عملية نشر جديدة ← تطبيق ويب، التنفيذ باسم «أنا»، الوصول «أي شخص». انسخ رابط `/exec` والصقه في تبويب «الربط» داخل التطبيق.
3. **سيري والتنبيهات:** الخطوات كاملة مع الروابط الجاهزة للنسخ في تبويب «الربط».

## روابط السيرفر

| الرابط | وش يسوي |
|---|---|
| `?q=اكلت 3 بيضات` | يسجل ويرد بجملة لسيري |
| `?hint=food&q=…` | نفسه، وإذا ما عرف الأكلة يقدرها |
| `?action=status` | وضعك اليوم |
| `?action=nudge` | تنبيه إذا فيه شي يستاهل، وفاضي إذا لا (للأتمتة) |
| `?action=week` | تقرير الأسبوع |
| `?action=suggest` | وش تاكل الحين |
| `?action=data&callback=fn` | كل البيانات للتطبيق (JSONP) |

السعرات تقديرية من جداول التغذية وقوائم المطاعم. أكلة ما يعرفها؟ علّمه إياها من التطبيق مرة وحدة.
